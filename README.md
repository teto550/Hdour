# حضور — خدمة ابتدائي البابا اثناسيوس

الكود اتقسم من ملف `index.html` واحد (٦٧٠٠ سطر) لملفات صغيرة منظمة، عشان أي تعديل بعد كده تبعت بس الملف المعني بدل الكود كله.
**السلوك مقصود يفضل زي ما هو بالظبط — ده تنظيم بس، من غير تغيير في الوظايف.**

## الهيكل

```
index.html        هيكل الصفحة بس (بيحمّل الستايل والواجهات والسكربتات)
manifest.json     إعدادات الـ PWA
sw.js             الـ Service Worker (الأوفلاين) — فيه قايمة كل الملفات
css/              الستايل (١٤ ملف، الترتيب في index.html مهم)
views/            الواجهة (HTML) — كل شاشة / تاب / نافذة في ملف
  app/ tabs/ modals/
js/
  boot.js         بيحمّل views/ ويحطها في index.html وبعدها يشغّل main.js
  main.js         بيستورد كل ملفات البرنامج بالترتيب
  core/           الأساسيات (إعدادات، Firebase، الحالة المشتركة، كاش، toast)
  lib/            دوال مساعدة (مطابقة الأسماء العربي…)
  features/       ميزات البرنامج (كل ميزة في ملف)
  ui-effects.js, install-banner.js   سكربتات صغيرة عادية
```

## عايز تعدّل إيه؟ افتح إيه؟

| عايز تعدّل | الملف |
|---|---|
| نص / زرار / مكان عنصر في شاشة | الملف المناسب في `views/` (مثلًا `views/tabs/attendance.html`) |
| لون / حجم / شكل | الملف المناسب في `css/` (مثلًا `css/modals.css` للنوافذ، `css/lists.css` لقوائم المخدومين) |
| إيميل الأدمن أو إعدادات Firebase | `js/core/config.js` |
| متغير مشترك بين أكتر من ملف | `js/core/state.js` |
| منطق ميزة معينة | الملف المناسب في `js/features/` (الجدول تحت) |

## قواعد مهمة (٤ بس)

1. **الحالة المشتركة:** أي متغير بيتقرا أو بيتعدّل من أكتر من ملف اتحط في `js/core/state.js` وبنوصله بـ `S.اسم_المتغير` (مثلًا `S.allStudents` و `S.currentRole`). المتغيرات اللي بتتستخدم جوه ملف واحد بس فضلت جوه الملف.
2. **الدوال اللي بتتنادى من HTML** (`onclick="..."`) لازم تتعرّف على `window` (زي `window.switchTab = ...`) — زي ما كانت بالظبط.
3. **ملف JS جديد:** اعمله في `js/features/` وضيف سطر `import './features/اسمه.js';` في `js/main.js`. لو ملفك محتاج دالة من ملف تاني، اعمل `export` للدالة هناك و`import` عندك.
4. **ملف جديد (JS / CSS / view):** ضيفه كمان في `SHELL_FILES` جوه `sw.js` عشان يشتغل أوفلاين من أول مرة (مش إجباري، بيتحفظ لوحده بعد أول فتحة أونلاين). ولو عملت view جديد ضيف سطر `<div data-include="views/..."></div>` في مكانه في `index.html`.

## تشغيل محلي

الملف مش هيفتح بدبل-كليك (`file://`) لأن المتصفح بيمنع تحميل الملفات كده. شغّل أي سيرفر بسيط من فولدر المشروع:

```
python -m http.server 8000
```

وافتح `http://localhost:8000`.

## النشر على GitHub Pages

انسخ كل محتويات الفولدر ده فوق الريبو (استبدل `index.html` و `sw.js`)، وارفع. الـ Service Worker بيجيب ملفات التطبيق من النت الأول، فأي تعديل بيوصل من أول فتحة بعد الرفع.
